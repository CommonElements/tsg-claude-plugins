description: Show your Voydar API plan, credits remaining and commercial-use status
---

Call the Voydar MCP tool `get_usage` (it's free) and report in three lines: the plan, the monthly credits (used, remaining and the reset date), and the commercial-use status (what the plan permits). If the tool isn't connected, tell the user to run `/mcp` and sign in to **voydar**. If credits are low, mention https://www.voydar.com/pricing.
